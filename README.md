# memorial

誕生日・記念日管理Webアプリ - 大切な人の記念日を忘れないために

## 概要

React + Supabase で構築された、人物中心の記念日管理アプリケーションです。
大切な人の誕生日や記念日を管理し、適切なタイミングで通知を受け取ることができます。

## 技術スタック

- **フロントエンド**: React 18 + Vite
- **バックエンド**: Supabase (Database, Auth, Storage)
- **スタイリング**: Tailwind CSS
- **状態管理**: Zustand + React Query
- **フォーム管理**: React Hook Form + Zod

## 開発環境のセットアップ

```bash
# 依存関係のインストール
npm install

# 開発サーバーの起動
npm run dev

# ビルド
npm run build

# プレビュー
npm run preview
```
