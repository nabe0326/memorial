# Memorial

🎂 誕生日・記念日管理Webアプリ - 大切な人の記念日を忘れないために

## 概要

React + Supabase で構築された、人物中心の記念日管理アプリケーションです。
大切な人の誕生日や記念日を管理し、適切なタイミングで通知を受け取ることができます。

## ✨ 主な機能

- **👥 人物管理**: 大切な人の情報を登録・管理
- **📅 イベント管理**: 誕生日・記念日・その他のイベントを追加
- **⏰ 通知機能**: イベント毎に通知日数と時刻を個別設定
- **📱 レスポンシブデザイン**: スマートフォン・タブレット・デスクトップ対応
- **🔐 認証システム**: メール/パスワード + Googleアカウント対応
- **📊 ダッシュボード**: 今後のイベント一覧表示
- **📈 タイムライン**: 時系列でのイベント表示
- **🗓️ カレンダー**: 月次カレンダービュー
- **🔍 検索機能**: 人物・イベントの高速検索

## 🛠️ 技術スタック

- **フロントエンド**: React 18 + Vite
- **バックエンド**: Supabase (Database, Auth, Storage)
- **スタイリング**: Tailwind CSS
- **状態管理**: Zustand + React Query
- **フォーム管理**: React Hook Form + Zod
- **カレンダー**: React Big Calendar
- **日付処理**: date-fns
- **UI コンポーネント**: Headless UI + Heroicons

## 🚀 開発環境のセットアップ

### 1. 依存関係のインストール
```bash
npm install
```

### 2. 環境変数の設定
`.env.local` ファイルを作成し、Supabaseの設定を追加：
```bash
VITE_SUPABASE_URL=your_supabase_url
VITE_SUPABASE_ANON_KEY=your_supabase_anon_key
```

### 3. 開発サーバーの起動
```bash
npm run dev
```

### 4. その他のコマンド
```bash
# ビルド
npm run build

# プレビュー
npm run preview

# Lint
npm run lint
```

## 🗄️ データベース設計

### persons テーブル
- 人物の基本情報（名前、関係性、メモ等）

### events テーブル
- イベント情報（タイトル、日付、カテゴリ、通知設定等）

## 🔔 通知機能

- **個別設定**: イベント毎に通知日数と時刻を設定可能
- **ブラウザ通知**: デスクトップ・モバイル対応
- **通知種類**: 誕生日・記念日・その他を個別に設定

## 📱 レスポンシブ対応

- **タブレット**: 768px〜
- **デスクトップ**: 1024px〜

- ユーザー毎のデータ分離
