# Memorial App - プロジェクト全体タスク概要

## プロジェクト目標
大切な人の誕生日・記念日を管理するWebアプリケーション

## 技術スタック確認
- [✅] React 18 + Vite セットアップ
- [✅] Supabase 依存関係インストール
- [✅] Tailwind CSS セットアップ
- [✅] React Query, Zustand セットアップ
- [✅] フォーム管理（React Hook Form + Zod）
- [✅] UI コンポーネント（Headless UI + Heroicons）

## 主要機能一覧

### 🔴 Core Features (必須)
1. **認証システム**
   - ユーザー登録・ログイン
   - Google OAuth連携
   - パスワードリセット

2. **人物管理**
   - 人物CRUD操作
   - 関係性管理
   - プロフィール画像対応

3. **イベント管理**
   - 記念日CRUD操作
   - 人物との紐づけ
   - 繰り返し設定

4. **ダッシュボード**
   - 直近イベント表示
   - 人物カード一覧
   - 基本統計情報

### 🟡 Advanced Features (重要)
5. **カレンダービュー**
   - 月/週/日表示
   - イベントの可視化
   - ドラッグ&ドロップ編集

6. **タイムライン**
   - 時系列イベント表示
   - 無限スクロール
   - フィルタリング

7. **検索・フィルター**
   - 人物検索
   - 関係性フィルター
   - 日付範囲指定

### 🟢 Production Features (必要に応じて)
8. **通知システム**
   - メール通知
   - ブラウザ通知
   - 通知タイミング設定

9. **PWA対応**
   - オフライン対応
   - ホーム画面追加
   - プッシュ通知

10. **最適化・テスト**
    - パフォーマンス最適化
    - ユニットテスト
    - E2Eテスト
