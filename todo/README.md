# Memorial App - Task Management

このフォルダには、Memorial アプリ開発のタスク分解と進捗管理のファイルが含まれています。

## ファイル構成

- `phase1-mvp.md` - Phase 1（MVP）のタスク
- `phase2-advanced.md` - Phase 2（高度な機能）のタスク  
- `phase3-production.md` - Phase 3（本番リリース）のタスク
- `project-overview.md` - プロジェクト全体のタスク概要

## 開発フェーズ

### Phase 1 (MVP) - 2週間
基本的な CRUD 機能とダッシュボードを実装

### Phase 2 (高度な機能) - 1週間
カレンダービューやタイムライン、検索機能を実装

### Phase 3 (本番リリース) - 1週間
通知機能、PWA対応、テスト、デプロイ

## タスクの進捗管理

各フェーズのファイルでは、以下の形式でタスクを管理します：

- [ ] 未着手
- [🔄] 進行中
- [✅] 完了
- [❌] ブロック中

優先度は以下で表記：
- 🔴 高優先度
- 🟡 中優先度  
- 🟢 低優先度
